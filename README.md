# 9Devy LLC Website

This repository contains the custom WordPress theme and plugins for the 9Devy LLC website, a premium creative studio specializing in videography, photography, and social media optimization.

## Project Goals
- Build a high-end, SEO-optimized website reflecting the quality of luxury brands like Nike, Gucci, Cartier, and Apple.
- Showcase a modern portfolio with filterable gallery options for videography, photography, and social media optimization.
- Enable service sales through a shop section with secure checkout (Square, Stripe, or similar).
- Build a community with an email list or subscriber form for updates and campaigns.
- Track engagement using Google Analytics, VIDIQ (for YouTube), and other tools.
- Ensure legal compliance with BOI reporting, EIN display (33-4380890), Terms of Service, Privacy Policy, and Disclaimer pages.

## Repository Structure
- `README.md`: This file

  - `style.css`

  - `assets/`
    - `css/`
    - `js/`
    - `images/`
  - `templates/`
  - `inc/`
- `plugins/`: Custom plugins (if any)
- `static/`: Legacy static files (index.html, placeholderstyles.css, Placeholderscript.js)
- `.github/`: GitHub configurations (workflows, issue templates)

## Setup Instructions
1. Clone this repository: `git clone https://github.com/The9Devy/9devy-site.git`
2. Install WordPress on your server (e.g., via Bluehost, SiteGround, or locally with Local by Flywheel).
3. Copy `theme/9devy-theme/` to `wp-content/themes/` in your WordPress installation.
4. Activate the theme in the WordPress dashboard.
5. Install plugins (e.g., Yoast SEO, WooCommerce, Mailchimp).
6. Create pages (Homepage, About, Services, Portfolio, Blog, Shop, Contact, Legal Pages).
7. Configure integrations (Google Analytics, VIDIQ, payment gateways).
8. Test for mobile responsiveness, accessibility, and performance.
